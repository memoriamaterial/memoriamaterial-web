Deberán desarrollar la experiencia en formato Web Interactiva, teniendo en cuenta que la web permite narrar visualmente el proyecto de una manera más dinámica.


Pueden aprovechar recursos como:

Pop ups. Audio. Video. Imágenes. Animaciones. Recorridos visuales. Interacciones.

La web deberá ayudar a contar la experiencia de una manera simple y clara.
