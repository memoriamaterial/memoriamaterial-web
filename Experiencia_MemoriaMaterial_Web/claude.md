# Proyecto: Memoria Material

## Qué es
Web interactiva que narra la experiencia
Consigna completa en brief/consigna.md.

## Requisitos obligatorios
- Escenarios bien presentes y cuidados visualmente; si un escenario necesita más de una pantalla, usarlas.
- Al menos 2 voces producidas con audio real (ver guion); el resto aparece como texto.
- Recursos: pop-ups, audio, video, imágenes, animaciones, recorrido visual, interacciones.
- Que cuente la experiencia de forma simple y clara.

## Identidad (leer antes de diseñar)
- Paleta: brief/paleta.md
- Motion: brief/motion.md
- Fotografía: brief/fotografia.md
- Logo y tramas: assets/logo, assets/tramas

## Stack
HTML + CSS + JS (o el que prefieras), GSAP + ScrollTrigger para el recorrido.

## Forma de trabajo
- Construir de a un escenario por vez y mostrarlo antes de seguir.
- Usar solo los colores de la paleta.
- Debe funcionar en celular.

## Skills a usar
- Dirección visual y layout: impeccable, frontend-design, taste-skill
- Recorrido por scroll: scroll-world, gsap-scrolltrigger
- Animación: gsap-core, gsap-timeline, choreograph, animate
- Pulido: improve-animations, animation-performance
- Celular: mobile-native
- Testeo final: break-ui
Antes de cada tarea, revisá qué skills de esta lista aplican y usalas.
